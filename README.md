# Diabetes Prediction Final Results

This folder contains the final reproducible code, processed outputs, and presentation figures for Group 4's diabetes prediction project using the CDC BRFSS 2015 diabetes health indicators dataset.

## Contents

- `cs760-G4.ipynb`: main executed notebook for data preparation, model training, evaluation, fairness analysis, and plotting.
- `cs760-G4_fixed.py`: script exported from the executed notebook for reproducibility.
- `diabetes_012_health_indicators_BRFSS2015.csv`: dataset used in the experiments.
- `final_outputs/`: model metrics, classification reports, confusion matrices, subgroup fairness results, selected settings, and feature-importance tables.
- `final_charts/`: figures used for the final presentation.

## Evaluation Summary

The project evaluates Logistic Regression, Random Forest, XGBoost, and a Neural Network (MLP) on an untouched test set. Because the dataset is imbalanced, model comparison uses accuracy, balanced accuracy, Macro-F1, and class-specific recall rather than accuracy alone.

Current final results by Macro-F1:

- Neural Network (MLP): Macro-F1 = 0.4478, Accuracy = 0.8370, Diabetes Recall = 0.4148
- Random Forest: Macro-F1 = 0.4315, Accuracy = 0.6917, Diabetes Recall = 0.7277
- Logistic Regression: Macro-F1 = 0.4292, Accuracy = 0.6474, Diabetes Recall = 0.5971
- XGBoost: Macro-F1 = 0.4210, Accuracy = 0.6368, Diabetes Recall = 0.6561

The final best model by Macro-F1 is the Neural Network (MLP). Random Forest remains an important comparison point because it achieves the strongest diabetes recall among the evaluated models. Pre-diabetes recall remains the main limitation across the models.

## Decision Weights

Validation-selected decision weights are applied consistently in the final metrics and diagnostic plots. In the final run, LR, Random Forest, and XGBoost use `[1.0, 1.0, 1.0]`, while MLP uses `[1.0, 1.0, 2.0]`.

## Explainability

SHAP artifacts are included as XGBoost-based tree model explanations for diabetes-class risk factors. This explainability model is separate from final model selection: the final predictive model is selected by Macro-F1, while XGBoost is used for tree-based SHAP interpretation.

The included SHAP feature-importance table ranks the top factors as GenHlth, HighBP, BMI, Age, HighChol, Income, HeartDiseaseorAttack, DiffWalk, MentHlth, and NoDocbcCost.

## Reproducibility

The notebook uses `RANDOM_STATE = 42` and stratified train/validation/test splits. Core model outputs can be regenerated by running `cs760-G4.ipynb` from top to bottom. To regenerate SHAP figures, install the optional `shap` dependency before running the SHAP section.
